Split Pane

A resizable split layout with a draggable divider. Mark the two panels with emrSplitFirst and emrSplitSecond. Drag the divider with a mouse, pen or touch, or focus it and use the arrow keys (Home/End jump to the limits). Supports horizontal and vertical orientations, minimum/maximum constraints, and can persist the size to localStorage via storageKey.
