Context Menu

Context menus show actions for an element when it is right-clicked, long-pressed on touch devices, or receives the context menu key. The menu opens at the pointer position and supports icons, keyboard shortcuts, nested submenus, checkbox and radio items, and Material 3 Expressive grouped segments. Keyboard navigation, typeahead and focus management come from the Angular CDK menu.
